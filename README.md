### "Mod Manager Won't Load"
- **Solution:** Right-click the application and select "Run as Administrator"
- Ensure Windows SmartScreen is allowing the app to run

### "I Can't See My Installed Mods"
- **Solution:** Check that your mods are in the `Mods` folder
- Click "Refresh" in the application to rescan
- Make sure you've selected the correct game installation path

### "Script Extender Not Working"
- **Solution:** Click "Reinstall" in the Script Extender tab
- Verify your antivirus isn't blocking the application
- Update BG3 Mod Manager Redux to the latest version

### "Mods Not Appearing in Game"
- **Solution:** Double-check your load order in the mod manager
- Ensure mods are compatible with your game version
- Try enabling mods one at a time to identify conflicts
